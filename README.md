# لوحة تحكم الجدول الدراسي — خريف 2026

لوحة تحكم تفاعلية لجدول كلية الصيدلة، جامعة طرابلس — العام الجامعي 2026/2027.
مبنية على بطاقة "الجدول الدراسي — خريف 2026" (الجدول النظري 8/8/2026 · جدول
المعامل وجدولا الامتحانات 27/8/2026).

An interactive control panel for a Fall 2026 pharmacy timetable, built from the
printed A3 reference card. Single self-contained HTML file — no build step, no
server, works offline.

## التشغيل / Running

افتح `index.html` في المتصفح مباشرة. لا توجد اعتماديات ولا خطوة بناء.

```
open index.html
```

الخطوط تُحمَّل من Google Fonts؛ بدون اتصال تعمل اللوحة بخطوط النظام.

## ما تفعله اللوحة

| القسم | الوظيفة |
|---|---|
| **الحالة الآن** | ساعة حيّة تعرض الحصة الجارية ومتبقّي وقتها، أو الحصة التالية، أو عدّاد بداية الفصل |
| **المؤشرات** | أيام الدراسة · عدد النظري/العملي · أبكر بداية · آخر انتهاء · التعارضات · الامتحان القادم — تُحسب كلها من البيانات وتتغيّر مع المرشِّحات |
| **الأسبوع الدراسي** | لوح أربعة أيام بمقياس زمني 8:30 ص – 6:00 م، مع خط "الآن"، والحصص المتداخلة تُوزَّع على مسارات متجاورة |
| **سجل المقررات** | ستة مقررات، ولكل حصة مفتاح حضور يعيد حساب اللوح والتعارضات فوراً |
| **خريطة الامتحانات** | شريطا النصفية والنهائية بلون كل مقرر، وقائمة امتحانات مرتّبة بعدّاد أيام |
| **التقويم الأكاديمي** | مواعيد الفصل بحالة (منقضٍ · جارٍ · قادم) نسبةً إلى التاريخ المرجعي |

### أدوات التحكم

- **المقررات** — إخفاء/إظهار أي مقرر عبر اللوح والسجل وخريطة الامتحانات معاً.
- **نظري / عملي / إظهار غير المحضور** — مرشِّحات عرض.
- **التاريخ المرجعي** — يحرّك كل العدّادات وحالة التقويم لأي يوم (افتراضه اليوم).
- **تصدير ICS** — يولّد تقويماً بالحصص الأسبوعية المتكررة ومواعيد الامتحانات، وينسخه إلى الحافظة.
- **طباعة** — تنسيق A3 عمودي مطابق للبطاقة الأصلية.
- **استعادة الأصل** — يرجع إلى بيانات البطاقة المطبوعة.

تُحفَظ المرشِّحات ومفاتيح الحضور في `localStorage` لكل متصفح على حدة.

## محرّك التعارضات

المحاضرات الثلاث المؤشَّرة "لا يُحضَر" في البطاقة ليست مخفيّة — هي مُطفأة وقابلة
للتشغيل، وعند تشغيلها تُبيّن اللوحة سبب إهمالها:

- **تحليل صيدلي I** نظري (الأربعاء 8:30–10:30 ص) — يتداخل 90 دقيقة مع معمل صيدلة سريرية II.
- **علم السموم الصيدلاني** نظري (الأربعاء 10:30 ص–12:30 م) — يتداخل 90 دقيقة مع المعمل نفسه.
- **ممارسة صيدلية II** نظري (الأحد 8:30–10:30 ص) — لا يتعارض، لكنه يفتح يوماً خامساً خارج الأربعة أيام.

الإعداد الافتراضي (كما في البطاقة) يعطي **صفر تعارضات**.

## البيانات

كل البيانات مضمّنة في `index.html` في ثلاثة ثوابت في أعلى `<script>`، وهي المصدر
الوحيد للحقيقة:

- `COURSES` — ستة مقررات: الرمز، الاسم بالعربية والإنجليزية، اللون، حصة نظري،
  حصة عملي، امتحان نصفي، امتحان نهائي. الأوقات بالدقائق من منتصف الليل،
  والأيام `0=الأحد … 6=السبت`.
- `CALENDAR` — مواعيد التقويم الأكاديمي.
- `DAY_AR` / `MON_AR` / `STUDY` / `FREE` — أسماء الأيام والشهور وتقسيم أيام الأسبوع.

لتعديل الجدول، حرّر `COURSES` فقط؛ اللوح والمؤشرات وخريطة الامتحانات والتعارضات
والتصدير تُشتق منها كلها.

ألوان المقررات مأخوذة حرفياً من متجهات البطاقة الأصلية:

| المقرر | الرمز | اللون |
|---|---|---|
| صيدلة سريرية II | P534PT | `#0e6a6a` |
| صيدلة صناعية II | P552PT | `#1d5c86` |
| كيمياء عقاقير II | P342PT | `#96700f` |
| علم السموم الصيدلاني | P532PT | `#2c7a57` |
| ممارسة صيدلية II | P522PT | `#694c8e` |
| تحليل صيدلي I | P511PT | `#9a5730` |

### فرق مقصود عن البطاقة المطبوعة

مؤشّر "نظري / عملي" في البطاقة مطبوع **3 · 5**، بينما السجل نفسه يُدرج ست حصص
عملية (واحدة لكل مقرر). اللوحة تحسب المؤشّر من البيانات فتعرض **3 · 6**. يُنصح
بمراجعة الرقم مع قسم الدراسة والامتحانات.

## ملاحظات التشغيل من البطاقة

- نظري صيدلة صناعية II المعتمد هنا هو **المجموعة (B)** — الثلاثاء 12:30 م.
  المجموعة (A) موعدها السبت وتفتح يوماً خامساً.
- المحاضرات المهمَلة نظرياً **امتحاناتها إلزامية**.
- الحصة الوحيدة المتأخرة هي معمل كيمياء عقاقير (الثلاثاء 3:00 – 6:00 م) ولا بديل لها.
- راجع أرقام المجموعات مع قسم الدراسة والامتحانات قبل **10/09/2026**.
